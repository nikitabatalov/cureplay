# CurePlay 2.1: открыть и собрать

1. Закрой предыдущий CurePlay: ПКМ по значку возле часов → **Выход**.
2. Распакуй архив в отдельную папку, например `C:\Projects\CurePlay-2.1` (не запускай из архива).
3. В Visual Studio 2026: **Файл → Открыть → Проект или решение** → `CurePlay\CurePlay.csproj`.
4. **Ctrl+Shift+B** — сборка. Потом **F5** — запуск. Если появятся ошибки, отправь скриншот вкладки «Список ошибок».
5. Крупная кнопка **BOOST NOW** запускает только безопасную проверку. Зелёная кнопка **Smart Boost ON/OFF** включает/отключает автоматические проверки.
6. **CureNet → Choose Test Target** — выбирай Cloudflare, Google, Франкфурт, Стокгольм и другие узлы либо введи IP/домен. Затем нажми **Применить**. При блокировке ICMP увидишь «Нет ответа».
7. **Disk Health** — увидишь «Здоров», «Внимание», «Проблема» или «Нет данных», подробности — по кнопке.
8. **Processes** — значки и CPU/RAM, явное подтверждение закрытия.
9. **Settings** — RAM-диагностика, порог температуры (по умолчанию **93 °C**), монитор сети.
10. **Stutter Lab** — авто-отслеживание перегрузок, отдельная кнопка на **официальный PresentMon** для точного времени кадра.

## Сделать EXE без GitHub

В папке с архивом дважды нажми `build-local.cmd`. После успеха появится `publish\CurePlay.exe`.
**Не копируй один exe отдельно** — для этой версии нужны файлы из всей папки `publish`.

Если командный файл не сработал, открой PowerShell в каталоге и выполни:

```powershell
dotnet restore .\CurePlay\CurePlay.csproj -r win-x64
dotnet publish .\CurePlay\CurePlay.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -o .\publish
```

**Ограничения:** данные GPU/SMART/RAM зависят от железа и драйверов. Ping — измерение до выбранного узла, не до игровой сессии. Мониторинг нагрузки системы не равен измерению микрофризов кадра. CurePlay не меняет BIOS и не «разгоняет» RAM.
